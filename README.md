# Revienta Burbujas

Juego arcade para 1 o 2 jugadores: dispara hacia arriba y parte las burbujas hasta limpiar la pantalla.

- Mismo dispositivo: 1 o 2 jugadores (táctil, teclado o mandos).
- Online: uno crea la partida y el otro se une con el código de 4 letras.
- Se puede instalar en el móvil como app (menú del navegador → Instalar / Añadir a pantalla de inicio).
